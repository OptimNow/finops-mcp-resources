# MCP Clients Overview

**Last Updated**: March 2026

Quick reference guide for all MCP clients and how to choose the right one for your FinOps needs.

---

## Quick Decision Guide

**I'm a developer/engineer managing infrastructure as code**
→ Try [Claude Code](./claude-code.md) or [Kiro](./kiro.md) (AWS-focused)

**I'm in finance/business and need cost insights**
→ Try [ChatGPT](./chatgpt.md) or [Claude Desktop](./claude-desktop.md)

**I'm AWS-focused**
→ Try [Kiro](./kiro.md) or [Kiro CLI](./kiro-cli.md)

**I'm Azure-focused**
→ Try [Microsoft Copilot](./copilot.md)

**I'm GCP-focused**
→ Try [Google Gemini](./gemini.md)

---

## All MCP Clients

### For Developers & Technical Teams

| Client | Best For | Key Features | MCP Support |
|--------|----------|--------------|-------------|
| [Claude Code](./claude-code.md) | DevOps/IaC workflows | Remote MCP, task workflows, enterprise controls | Native, remote servers |
| [Kiro](./kiro.md) | AWS DevOps teams | Spec-driven development, agent hooks, AWS integration | Native, remote servers (preview) |
| [VS Code + Cline](./vscode-cline.md) | General development | Extensible, familiar, wide ecosystem | Via extensions |
| [Cursor](./cursor.md) | Modern IDE users | Developer-focused, AI-native | Native |

### For Business & Finance Stakeholders

| Client | Best For | Key Features | MCP Support |
|--------|----------|--------------|-------------|
| [ChatGPT](./chatgpt.md) | Non-technical users | Most accessible, huge user base, conversational | Native (March 2025) |
| [Claude Desktop](./claude-desktop.md) | Quick demos & exploration | Fast prototyping, native MCP support | Native |
| [Microsoft Copilot](./copilot.md) | Microsoft 365 orgs | Teams/Excel/PowerPoint integration | GA in Copilot Studio |
| [Google Gemini](./gemini.md) | GCP teams | BigQuery integration, Vertex AI, multi-modal | Native (April 2025) |

### By Cloud Provider

| Client | Cloud Provider | Key Features |
|--------|----------------|--------------|
| [Kiro](./kiro.md) | AWS | Backed by AWS, deep AWS service integration |
| [Microsoft Copilot](./copilot.md) | Azure | Azure Cost Management, native Azure integration |
| [Google Gemini](./gemini.md) | GCP | BigQuery billing exports, Cloud integration |
